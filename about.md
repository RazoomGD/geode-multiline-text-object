# Multiline Text Object

Allows you to create multi-line text objects in the editor. 

Previously, this functionality was hidden by the RobTop and you could do this only by editing level code. But with this mod you can do this very easily. 

The mod can be useful for creators who make levels with a lot of text, especially minigames and platformers.

<cy>To insert a new line at cursor position</c>

- On PC use 'Enter' key
- On mobile use the 'New Line' button
